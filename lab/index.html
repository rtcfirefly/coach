The whole question is phone behaviour, so run this on the phone you actually train with — desktop numbers do not transfer.

1b · Accuracy against a target phrase no download

Read the phrase aloud; the harness scores word error rate against it. This is the number that decides whether Web Speech is good enough — run it quiet, then again mid-set with music and plates going.

1c · Gym-noise stress no download

Plays shaped noise through the speaker while you talk, so you can test recognition and barge-in without going to the gym. Echo cancellation is what should stop this bleeding into the mic — if the VAD fires on the noise alone, AEC is not doing its job on this device.

2 · Voice bench no download

Coach lines, not lorem ipsum — how a voice handles "one thirty five" and "Romanian deadlift" is what matters, and TTS engines differ most on numbers and proper nouns. Play the same line through every installed voice, then shortlist and A/B the survivors.

2b · Neural voice (Piper) ~77 MB download

Downloads ONNX Runtime and a Piper voice, then synthesises the same coach line so you can A/B it against the system voices above. Both are SHA-256 verified against registry.json before use and cached, so this is a one-time cost.

2c · Kokoro ~95 MB download

Rated above Piper in the research. Runs on raw ONNX Runtime with the same vendored g2p — measured 100% vocab coverage, so no extra phonemizer.

3 · Voice activity detection no download

The module from js/vad.js. Watch the noise floor adapt, then check it still triggers on speech with music and plates in the background.

4 · Downloadable models

Every asset below is pinned to a SHA-256 in registry.json, taken from Hugging Face's published lfs.oid. Nothing is fetched until you approve it, and every byte is hash-verified in the browser before it is handed to the runtime — a mismatch aborts.
